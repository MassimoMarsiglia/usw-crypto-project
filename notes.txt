# Data Understanding
- Strongest Positive Correlation
    + represented by the highest numerical value closest to +1 and shown by the most intense color
    + assets with strong positive correlation (0.85 to 0.95) are highly interdependent. If we buy one, we effectively get exposure to the other
    + exp: BTC and ETH often driven by the same market sentiment

- Strongest Negative Correlation
    + represented by the lowest numerical value closest to -1 and is shown by the most intense color in the negative side of the color scale
    + assets with strong negative correlation (-0.50  to -1.00) move in opposition
    + this is extremely valuable for portfolio diversification and rish management. If one asset loses value, the other is likely to gain value 

- Weakest Correlation 
    + is the value closet to 0 and is shown by the most neutral color
    + these assets have the least linear relationship
    + a weak correlation (0.05 or -0.08) meaning one won't drag the other down in a market crash
    
# Features
- Trend indicators: EMA(9), EMA(21), EMA(50), EMA(200), MACD(12,26,9), ADX(14)
- Momentum indicators: RSI(14), StorchRSI, CCI(20), Momentum(10)
- Volatility indicators: ATR(14), Bollinger Bands(20,2), True Range
- Volume indicators: On-Balance Volume (OBV), Volume moving average
- Market structure signals: % Change (return), High-Low range, Candle body ratio 
- Returns: Return1, Return5 (1-bar and 5-bar percent change)
- BTC-pair relative streng: exp. ETH/USDT and ETH/BTC
    relative_strength = (ETH/BTC price normalized)

** Timeframe meaning:
15m -> short-term momentum 
1h -> market structure 
4h -> swing trend 
1d -> macro direction

# Split dataset

- We split the data based on timestamp, so:
    Dataset timestamps: 2025-01-01 00:00 → 2025-12-05 23:45 (15-min intervals)

- Split:

Train: first 70% of timestamps (e.g., Jan → Oct)

Validation: next 15% (Oct → Nov)

Test: last 15% (Nov → Dec)

- Meaning:

Train (first 700 rows): model sees historical data to learn patterns

Validation (next 150 rows): model checks if it generalizes to slightly newer unseen data

Test (last 150 rows): simulate real future predictions, evaluate performance
